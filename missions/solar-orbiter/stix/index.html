    Solar Orbiter STIX instrument database¶

    STIX is one of the ten Solar Orbiter instruments named in the spacecraft packet ICD; the Experiment Interface Document expands the acronym as "Spectrometer Telescope Imaging X-rays".16 On board it is the application owning process IDs 90 to 94 and the private services 236 to 240 of the spacecraft packet ICD.68 Its instrument database (IDB) - the instrument's packets, parameters, calibrations and commands written as SCOS-2000 MIB tables - is published on a server at FHNW (pub099.cs.technik.fhnw.ch), from which this wiki copied release 2.26.38.2 An instrument database uses the same tables as the spacecraft Solar Orbiter MIB; this page analyses every non-empty table of the copy and checks, row by row, how much of it is in the two copied spacecraft MIB releases. The same data can be browsed in the STIX explorer. The companion page for the SWA instrument is Solar Orbiter SWA instrument database; the documents that define what an instrument must provide are on Solar Orbiter instrument interfaces.

    Version: one vdf record¶

    The vdf table names the database version. The ICD defines VDF_NAME as up to 8 characters, a 32-character comment, and a domain identifier, release and issue number, all three optional; when several records exist, the last one imported names the database, and the importer cross-checks the domain identifier against its own domain option.22 The STIX IDB has exactly one record:3

    Field Value Remark
    VDF_NAME STX_226 7 characters: release 2, issue 26
    VDF_COMMENT PFM_applicable the spacecraft MIB release names also carry PFM
    VDF_DOMAINID 105 same number as the PCF_SUBSYS of 673 of the 681 parameters
    VDF_RELEASE / VDF_ISSUE 2 / 26

    The third number of the release name, 38, appears only in the folder and zip names; it is not stated in the available sources what it counts. The two spacecraft MIB releases copied by this wiki use domain 0 in their vdf (25925PFM and 10720PFM).45 Unlike the SWA IDB, which keeps its 70-version history in vdf (see SWA), the STIX file carries no history.

    APIDs and packet categories¶

    On Solar Orbiter the 11-bit APID is the 7-bit process ID followed by a 4-bit packet category, so APID = PID x 16 + CAT.96 The IDB uses nine telemetry APIDs:3

    APID PID / CAT Category meaning (Annex 8) Packets PUS types
    1441 90 / 1 TC verification 106 TM(1,1), (1,2), (1,7), (1,8)
    1444 90 / 4 routine housekeeping 2 TM(3,25) SIDs 1 and 2
    1447 90 / 7 event generation 84 TM(5,1)-(5,4), TM(17,2)
    1448 90 / 8 diagnostic 14 private services 236-239
    1449 90 / 9 dump 20 TM(6,6), TM(6,10)
    1451 90 / 11 context 1 TM(22,2)
    1468 91 / 12 private science 10 TM(21,6) X-ray and spectrogram
    1500 93 / 12 private science 8 TM(21,6) quick-look and calibration
    1509 94 / 5 functional cyclic 1 TM(3,25) SID 4 (inter-instrument data)

    Every packet sits in a category that Annex 8 of the packet ICD allows for its service: 1 for service 1, 4 for routine TM(3,25), 5 for inter-instrument TM(3,25), 7 for events and TM(17,2), 8 for the private reports ("private diagnostic packets produced upon Ground request"), 9 for dumps, 11 for service 22 and 12 for science.67 Annex 8 also offers category 6 for private fixed-length report packets produced on ground request; STIX does not use it, while SWA moved its private reports there (see Solar Orbiter instrument interfaces).63 Process ID 92 is not used; telecommands go to APID 1452 (PID 90, CAT 12) and one command to APID 796, process 49, the OBC "payload broadcast" process (see Commands).36 All 246 packets have PID_DFHSIZE = 16 (the 6-octet packet header plus the 10-octet data field header of Solar Orbiter telemetry), a packet time field (PID_TIME = Y), no CRC check (PID_CHECK = 0) and no SCOS-2000 event generation (PID_EVENT = N); 45 are variable packets with a vpd structure.33011

    Packet catalogue by PUS type and subtype¶

    SCOS-2000 identifies a packet by APID, type, subtype and up to two extra fields whose position the pic table gives per type and subtype; each combination has one pid row and one SPID.2530 The STIX pic rows place the first identification field at octet 20 (16 bits, the failure code) for TM(1,2) and TM(1,8), at octet 16 (8 bits, the SID or SSID) for TM(3,25) and TM(21,6), and at octet 16 (16 bits) for events and memory dumps; octet 16 is the first octet after the headers.3 The 246 SPIDs run from 54001 to 54365:3

    Type, subtype Packets Identification field What the packets are
    TM(1,1) / TM(1,7) 1 / 1 - acceptance success, completion success
    TM(1,2) 12 failure ID acceptance failures: the 8 standard IDs 0-7 and 48000, 48001, 48003, 48023
    TM(1,8) 92 failure ID completion failures 48005 to 48463
    TM(3,25) 3 SID SID 1 and 2 housekeeping (APID 1444), SID 4 inter-instrument data (APID 1509)
    TM(5,1) / (5,2) / (5,3) / (5,4) 25 / 29 / 26 / 3 event ID information, warning, error and high-severity events
    TM(6,6) / TM(6,10) 19 / 1 memory ID (TM(6,6) only) memory dumps per memory, memory check
    TM(17,2) 1 - connection test report
    TM(21,6) 18 SSID science data, see below
    TM(22,2) 1 - context report
    TM(236,16), (236,19) 2 - subsystem configuration report, FDIR parameter report
    TM(237,12), (237,20) 2 - start-up software (SuSW) and application software (ASW) parameter reports

    The private service types 236-239 are all within the range 236-240 that the packet ICD reserves for STIX; service 240 is not used.83 The pic table also defines TM(239,16), for which no packet exists.3 Each failure code and each event ID is its own packet, which is why service 1 (106 packets) and service 5 (83) make up 189 of the 246 definitions; the general mechanism is explained on How Solar Orbiter uses PUS.

    Failure codes and event IDs against the mission allocation¶

    Annex 9 of the packet ICD reserves failure IDs 0 to 500 for standard codes (0 illegal APID, 1 incomplete or invalid length, 2 wrong CRC, 3 illegal type, 4 illegal subtype, 5 illegal or inconsistent data, 6 illegal segment sequence flag, 7 illegal MAP ID) and gives STIX the block 48000 to 48999.13 STIX follows this: its TM(1,2) packets use the eight standard codes and its own codes start at 48000 (for example 48018 "Invalid HK data report period in TC(3,129)", 48035 "No Timecode within 2s after TC(9,129)").3 One description differs from the allocation: STIX's code 7 reads "Illegal segment sequence flag", the meaning the annex gives to code 6, where the annex assigns 7 to an illegal MAP ID.313

    For events the annex splits the 16-bit event ID by severity, the first two bits giving the report subtype (0x0000-0x3FFF for TM(5,1), 0x4000 for (5,2), 0x8000 for (5,3), 0xC000 for (5,4)), and each quarter into boot software, general application, specific application, "unexpected SW and HW errors", monitoring, OBCP and ESOC ranges; the annex makes this applicable to the central software and optional for other software.14 All 83 STIX event IDs respect both the severity bits and the ranges:3

    Subtype IDs Boot SW General application Unexpected SW/HW errors Monitoring
    TM(5,1) 0x0001-0x14A3 4 6 14 1 (0x14A3 "FDIR protection enabled")
    TM(5,2) 0x4001-0x5446 2 - 27 -
    TM(5,3) 0x8001-0x9450 2 3 21 -
    TM(5,4) 0xC001-0xD421 1 - 2 -

    The three high-severity events are requests to the spacecraft: execute a nominal sequence (0xC001), power down immediately (0xD420) and power cycle after an SDRAM initialisation time-out (0xD421).3

    SQL used (catalogue, failure and event IDs) 
    SELECT PID_TYPE, PID_STYPE, count(*) FROM pid GROUP BY 1, 2
 ORDER BY CAST(PID_TYPE AS INT), CAST(PID_STYPE AS INT);
SELECT * FROM pic ORDER BY CAST(PIC_TYPE AS INT), CAST(PIC_STYPE AS INT);
SELECT PID_SPID, PID_PI1_VAL, PID_DESCR FROM pid WHERE PID_TYPE = '1' ORDER BY 2;
SELECT PID_STYPE, CASE
         WHEN (v & 16383) BETWEEN 1 AND 31 THEN 'boot'
         WHEN (v & 16383) BETWEEN 32 AND 1055 THEN 'general'
         WHEN (v & 16383) BETWEEN 5152 AND 5279 THEN 'unexpected'
         WHEN (v & 16383) BETWEEN 5280 AND 13471 THEN 'monitoring' END, count(*)
  FROM (SELECT PID_STYPE, CAST(PID_PI1_VAL AS INT) v FROM pid WHERE PID_TYPE = '5')
 GROUP BY 1, 2;

    Housekeeping and the inter-instrument packet¶

    SID 1 (SPID 54101) and SID 2 (SPID 54102) carry the instrument housekeeping: software running (ASW or SuSW), instrument mode, DPU temperatures, currents and voltages, CPU load, SpaceWire counters and FDIR status (with per-channel FDIR masks and TC/TM counters in SID 1); SID 2 adds detector quadrant temperatures, high-voltage and attenuator status, aspect-system photodiode voltages and filesystem statistics.3 SID 2 also reports NIXD0077 "TC(20,128) seq cnt" (octet 88), which follows the packet ICD's recommendation that payloads report the sequence count of the last TC(20,128) they received.317 Their plf layouts end at octet 59 (last parameter, 16 bits, at octet 57) and octet 109 (32 bits at octet 105), but their tpcf sizes are 46 and 105; the 2025 spacecraft MIB has 59 and 109.34 The ICD defines TPCF_SIZE as the total SCOS-2000 packet length (recommended to include the 64- or 76-byte SCOS-2000 packet header), not imported into the run-time database nor used by any SCOS-2000 process, so the mismatch does not affect telemetry processing; if a mission uses the field to configure its history files, a size smaller than the real packet still files correctly, only more slowly.31

    SID 4 is the STIX contribution to on-board inter-instrument communication. The note SOL-SGS-TN-0007 asks STIX for a TM(3,25) with PID 94, CAT 5 and SID 4 at 1 Hz, carrying 16 octets for distribution: a 4-octet heartbeat copied from the OBT coarse time, thermal and non-thermal flare indices and a location status in one octet, signed Z and Y flare locations in arcminutes, a 4-octet flare duration, a 4-octet attenuator motion flag and a spare octet.19 The IDB packet YIX54103 (SPID 54103, APID 1509, 33 octets) implements exactly this layout:3

    The octet offsets, bit offsets and types are the plf and pcf entries; octet 21 is also defined as the 8-bit container NIXG0021.3 In the SCOS-2000 code table PTC 4 PFC 4 is an 8-bit signed integer and PTC 3 PFC 14 a 32-bit unsigned integer.33 The OBC copies these 16 octets into octets 191 to 206 of the TC(20,128) it distributes to the instruments.20

    The packet changed between the copied releases. In the April 2020 spacecraft MIB the flare octet held the location status at bit 1, the non-thermal index at bit 3 and a 3-bit thermal index at bit 5 (NIXD0059-NIXD0061), the attenuator flag was a single bit at octet 28 and a 32-bit filler followed at octet 29; the IDB moves the thermal index to bits 0-2, the location status to bits 5-6, makes the motion flag a 32-bit word, and introduces the new names NIXD0505-NIXD0507 and NIXG0021, so it now matches the TN-0007 byte table.5319 The old names stay in the IDB: NIXG0020 and NIXD0059-NIXD0061 (now described as "QL") are the flare fields of the quick-look packet 54122 "Flare flag and location".3 The 2025 MIB keeps the IDB layout but omits the final ZZPAD008 entry; the packet size stays 33 octets in all three databases.45 Browse it as packet 54103.

    Memory dumps and memory IDs¶

    Each of the 19 TM(6,6) packets is identified by its memory ID: 0xD000-0xD004 and 0xD011/0xD012/0xD021/0xD022 for the main unit's EEPROM, SRAM, SDRAM, two flash memories and four application-software image slots, the same values with 0xD1 for the redundant unit, and 0xDF00 for full memory access.3 The packet ICD allocates the memory IDs 0xD0-- and 0xD1-- to STIX, and its basic rules, for cross-access between redundant units, give unit B the unit A ID plus 256 (most significant byte 1), which is the main/redundant pattern seen here.15 The same 19 values form the textual calibration CIXT0014TM "Memory ID".3

    Science packets¶

    All STIX science travels as TM(21,6), the variable-length science packet with a structure identifier (SSID) in its first octet followed by fixed parameters and counted repeating blocks.16 The 18 SSIDs split over two APIDs:3

    APID SSIDs Products
    1468 (PID 91) 10-14, 20-24 X-ray levels L0 to L3 and spectrogram, each "auto" (10-14) and "user" requested (20-24)
    1500 (PID 93) 30-34, 41-43 quick-look summed light curves, background monitor, detector-specific spectra, variance, flare flag and location, background spectrum for calibration, aspect, TM management status and flare list

    These packets are defined in vpd, which lists the parameters in order and lets a parameter repeat the next VPD_GRPSIZE entries a number of times equal to its own value; groups may be nested, and VPD_OFFSET moves a parameter's start relative to the end of the previous one, a negative offset making two parameters overlap.32 STIX uses both features. The quick-look light-curve packet (SPID 54118) starts with SSID, SCET coarse and fine time, integration duration and detector mask, then the 16-bit NIXG0404 "SSID global 3" immediately followed by NIXD0407 "Pixel mask 1" with offset -12, so the 12-bit mask is read from the last 12 bits (bits 4 to 15) of the word just read; later, "Number of energies" (NIX00270) repeats a 2-entry group whose first entry, "Num of data pnts LC", itself repeats the compressed light-curve values.3

  A -. "repeated NIX00270 times" .-> B

    Parameters¶

    The 681 parameters are named by the Solar Orbiter convention: N for a monitoring parameter, a second letter I for instrument and X for STIX, as on the spacecraft MIB's name prefix table.4 Within the IDB:3

    Prefix Count Meaning in the data

    Monitoring checks and the three synthetic parameters¶

    Fourteen housekeeping parameters - DPU, SpaceWire, detector and attenuator currents and the DPU, reference, SpaceWire link, high and attenuator voltages - have monitoring checks, all on raw values (OCF_INTER = U, OCF_CODIN = I) and all to be confirmed by one sample (OCF_NBCHCK = 1).3 An ocp check applies only when its applicability parameter (OCP_RLCHK) is valid and equals OCP_VALPAR; checks are tried in order and the search stops at the first applicable check or soft/hard pair, unless the system is configured to apply all of them.34 STIX uses this to change limits with the instrument configuration, and the three synthetic parameters exist only to provide those applicability values. Each is a dynamic OL parameter (PCF_NATUR = D), whose source is an ASCII file named after the parameter in the synthetic/ folder, evaluated by SCOS-2000 when a contributing parameter changes.353

    Inference

    By the ICD's stop-at-first rule, the hard check at position 6 of NIXD0058 is reached only when none of the five soft checks applies, which happens only if NIXS0002 is invalid or outside 0-4, because a soft check followed by a soft check with a different criterion is not a soft/hard pair.34 The same holds for the trailing hard checks of NIXD0029 and NIXD0030. For NIXD0075 the order is soft (0 motors), soft (1 motor), hard (no criterion), soft (2 motors): with two motors moving, the search would stop at the hard check and the 2-motor soft limits (raw 28-870) would never be used. Whether ESOC configures SCOS-2000 to apply all applicable checks (the global option the ICD mentions) is not stated in the available sources. Note also that for four quadrants the hard high limit of NIXD0058 (546) is below the soft one (555).

    Commands¶

    The TC packet header¶

    The IDB defines one TC header, NOM_TC "STANDARD TC PKT", whose 13 pcdf elements give the packet header and the 4-octet PUS data field header bit by bit:3

    The element types F, A, P, K, T and S mean a fixed value, the command's APID, a value set by the command subsystem, and the acknowledgement flags, type and subtype taken from ccf.36 The layout is the spacecraft ICD's: 3-bit version 0, type 1, header flag 1, a 14-bit count and stand-alone sequence flags 0b11, a non-CCSDS secondary header with PUS version 1, and acknowledgement bits for acceptance (least significant) and completion (most significant).910 CCF_ACK = 9 = 0b1001 asks for both reports for every STIX command.337 The STIX header fixes the source ID to 0, whereas the packet ICD reserves ground source IDs 110-113, 120 (direct commands) and the spares 121-122, and the SWA IDB fixes 120; the 2025 spacecraft MIB's own NOM_TC uses an element of type O for it, a type that the ICD issue 7.0 list (F, A, T, S, K, P) does not define.312436

    • New in the IDB since April 2020: twelve parameters - the IIC flare octet NIXG0021 with NIXD0505-NIXD0507, the rotating-buffer fill level and file statistics NIXD0501-NIXD0504 in SID 2, NIXD0500 "SpW failure source", NIXD0448 "Bit reduction", NIXD0449 "Flare in progress" and NIX00490 "Averaging value Asp TC" - and the reworked SID 4 layout described above; the 2020 parameter NIX00441 "Delta time in 0.1 sec" is gone.35

    Inference

    The pattern - every IDB parameter and packet in the 2025 spacecraft MIB with identical definitions (apart from 10 units and 69 tpcf sizes), 2020 differences that the IDB resolves towards TN-0007, and 2025 additions (DARC flags, the bit-reduction field, the aligned TC(20,128), corrected record counts) absent from the IDB - suggests that the spacecraft MIB imports the STIX team's database and that ESA or the STIX team applied later changes on the MIB side. The 2.26.38 copy may also not be the latest IDB; the import process is not described in the available sources. The parallel analysis for SWA reaches the same conclusion (see SWA).

    Quality notes¶

    The following inconsistencies are visible in the data (this wiki's queries):3

    • CIXP0024TM declares 13 curve points (CAF_NCURVE) but has 14 cap rows, and six textual calibrations (CIXT0025TM, CIXT0340TM, CIXT0359TM, CIXT0401TM, CIXT1168TM, CIXTS001TM) declare a TXF_NALIAS different from their txp row count, as do two command text calibrations with PAF_NALIAS (CIXT0032TC declares 11 and has 8 pas rows, CIXT0080TC declares 5 and has 6); the ICD defines all three fields as the number of rows in the companion table.272829
    • Six commands have a CCF_NPARS different from their number of cdf elements: ZIX20128 (declares 0, has 11), ZIX37009 (115, 112), ZIX37010 (7, 66), ZIX37011 (116, 106), ZIX38006 (2, 3) and ZIX39015 (7, 10); ZIX17001 leaves the field empty and has no elements. The ICD offers the field for exactly this consistency check.38
    • SPID 54292 "Error - SDRAM init pattern memory test" has the TPCF_NAME YIX54929, not the YIX54292 the naming pattern of the other 245 packets would give.
    • The 2025 spacecraft MIB has every one of these counts consistent: CIXP0024TM declares 14 points, the six TXF_NALIAS and two PAF_NALIAS values equal their row counts, and the six commands' CCF_NPARS equal their cdf elements (ZIX17001 has 0). It keeps YIX54929.4
    • The tpcf sizes of variable packets mix 0 and 19 (see above), the sizes of HK SID 1 (46) and SID 2 (105) are shorter than their plf layouts (59 and 109 octets), and pic defines a TM(239,16) with no packet.31
