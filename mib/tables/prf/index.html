    prf.dat: Parameter range sets¶

    ICD 7.0 §3.3.3.7.1565 rows in Solar Orbiter 2025-09-16

    The prf table defines range sets, i.e. named sets of allowed values or value ranges that SCOS-2000 uses to check the values of command parameters (through CPC_PRFREF) and of sequence formal parameters (through CSP_PRFREF), one record per set; the individual ranges and discrete values are in PRV. A set may be shared by many parameters. Only parameters whose raw value is numerical or a time can be range checked; strings cannot. The record states whether the limits are written as raw or engineering values, the representation type of the limits (ASCII, signed or unsigned integer, real, absolute or relative time) and, for unsigned integers, their radix; these must be compatible with the type or engineering format of every parameter using the set. When a command sequence is loaded on a manual stack only the formal parameter values are checked against their range sets, not every value of the contained commands and sequences, although SCOS-2000 can be configured to check all parameter values at sequence loading time. The unit and the number of ranges are informative, for off-line consistency checks.1

    Key: PRF_NUMBR

    Fields¶

    #FieldTypeM/ODescription
    1PRF_NUMBRChar(10)MAlphanumeric name uniquely identifying the range set; referenced by CPC_PRFREF, CSP_PRFREF and PRV_NUMBR.
    Solar Orbiter: filled in 565 of 565 rows; e.g. CACP4901TC, VCD00147, VCD00149, VCD00150, VCD00153 ICD PDF p. 211
    2PRF_DESCRChar(24)OTextual description of the range set.
    Solar Orbiter: filled in 565 of 565 rows; e.g. Range Definition, Integer between 0 and 23, Integer between 1 and 23, Integer between 0 and 22, Integer between 0 and 25 ICD PDF p. 211
    3PRF_INTERChar(1)ORepresentation in which the limits PRV_MINVAL and PRV_MAXVAL of this set are written.
    • R Raw values (import default).
    • E Engineering values; allowed only if every parameter using the set is calibrated (CPC_CATEG/CSP_CATEG T or C).
    Default R. Solar Orbiter: filled in 565 of 565 rows; e.g. R, E ICD PDF p. 211
    4PRF_DSPFMTChar(1)ORepresentation type of the limit values in PRV, whose value formats are given in Appendix A. It must be compatible with the parameters using the set: with their PTC when PRF_INTER=R, and with their DISPFMT when PRF_INTER=E or for time parameters.
    • A ASCII.
    • I Signed integer.
    • U Unsigned integer (import default).
    • R Real.
    • T Absolute time.
    • D Delta/relative time.
    Default U. Solar Orbiter: filled in 565 of 565 rows; e.g. U, R, A, I ICD PDF p. 212
    5PRF_RADIXChar(1)ORadix of the limit values in PRV; only applicable for unsigned integers (PRF_DSPFMT=U). It may differ from the radix (CPC_RADIX/CSP_RADIX) of the parameters using the set.
    • D Decimal (import default)
    • H Hexadecimal
    • O Octal
    Default D. Solar Orbiter: filled in 549 of 565 rows; e.g. D, H ICD PDF p. 212
    6PRF_NRANGENumber(3)ONumber of PRV records defined for this set. Grey in ICD 7.0: not used by SCOS-2000 processing.
    Solar Orbiter: filled in 564 of 565 rows; e.g. 1, 2, 20, 5, 58 ICD PDF p. 212
    7PRF_UNITChar(4)OEngineering unit mnemonic, for consistency checking against the unit (CPC_UNIT/CSP_UNIT) of the parameters using the set. Grey in ICD 7.0: not used by SCOS-2000 processing.
    Solar Orbiter: filled in 100 of 565 rows; e.g. s, ms, #/nT, B, V ICD PDF p. 213

    Relationships¶

    • PRF_NUMBR → prv.PRV_NUMBR: Allowed values/ranges of the set (one-to-many); PRF_NRANGE should equal their number.
    • PRF_NUMBR → cpc.CPC_PRFREF: Command parameters checked against the set (many-to-one).
    • PRF_NUMBR → csp.CSP_PRFREF: Sequence formal parameters checked against the set.
    • PRF_UNIT → cpc.CPC_UNIT / csp.CSP_UNIT: Consistency check only.

    History across ICD issues¶

    ICD 5.1 (2001, section 3.3.3.7.1, PDF p.102-103) has the same seven fields and defaults (R, U, D) with PRF_NUMBR Number(4). The range set identifier became Char(10) in ICD 6.0 (Annex 1 of ICD 7.0, 'Range Set ID' item, PDF p.247); ICD 6.7 Draft A (PDF p.197-199), ICD 6.9 (PDF p.202-204) and ICD 7.0 (PDF p.210-213) are identical in structure. pyscos2000 (ICD 7.2) has the same seven columns and key, but gives PRF_DSPFMT the default R instead of the ICD's U.

    Notes from the extraction

    Default discrepancy: PRF_DSPFMT import default is 'U' in ICD 5.1, 6.9 and 7.0 but 'R' in pyscos2000 (7.2); a file leaving the field empty would be interpreted differently. Solar Orbiter always fills it, so the data are not affected. Solar Orbiter 2025-09-16: 565 range sets (531 in 2020); PRF_INTER R 549 and E 16; PRF_DSPFMT U 457, R 88, I 4 and A 16 (the 16 ASCII sets are exactly the engineering ones, holding lists of allowed alias texts); PRF_RADIX D 529, H 20, empty for the 16 ASCII sets. PRF_NRANGE disagrees with the PRV count for VCTX0001 (declares 104, has 101) and is empty for VNISLP01. Five sets are not referenced by any CPC or CSP record, while CSP_PRFREF 'VSM00001' points to a set that does not exist.

    In the Solar Orbiter MIB¶

    The 2025-09-16 release has 565 rows in prf.dat. Browse them through the MIB Explorer or read about the Solar Orbiter MIB.
