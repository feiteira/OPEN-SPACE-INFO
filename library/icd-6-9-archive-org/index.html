    Summary¶

    Version 6.9 (July 2010) of the SCOS-2000 Database Import ICD (EGOS-MCS-S2K-ICD-0001), the consolidated, signed issue that follows the 6.7 drafts. It is the final ICD for SCOS-2000 releases 5.3, 5.3.1 and 5.4 and merges changes made in parallel on several release lines. This copy comes from an archive.org mirror.

    Its structure is the same as 6.7. Chapter 2 covers file conventions, multi-domain installations and the FARC-based handling of sequences and displays. Chapter 3 defines the 51 tables field by field: monitoring parameters, calibrations (including conditional selection and logarithmic curves), limit checks, packet identification and processing, monitoring groups, displays, TC packet headers, commands with the optional dst routing table, sequences, verification, parameter sets, de-calibrations and range checks. Appendix A lists PTC/PFC types, Appendix B shows table relationships, and Appendix C covers PUS support by service.

    New in 6.9 compared with 6.7 Draft A: section 3.3.2.1.5 on System Control parameters, where the multi-domain SCTL application publishes server-family status as TM through MIB entries generated by SCTLgenerateMIB; an optional per-stage verification window, CVS_UNCERTAINTY, which overrides the default window; CVE_CVSID and CVP_CVSID aligned to Number(5); a new applicable System Control ADD; and an updated reference to NIS/NCTRS ICD Volume 2 issue 4.0.2. Annex 1 is a cumulative list of document changes from R4.0 to 6.9. Use this issue when you need the 2010-era baseline used by many ESOC missions before the 2017 version 7.0. The visible tracked-change residue shows exactly what was edited.

    Key points¶

    • Version 6.9 (06/07/2010) is the final ICD for S2K53, S2K531 and S2k54, consolidating changes from s2k52, s2k53, s2k531 and s2k4.51, with updated CVE_CVSID/CVP_CVSID fields and reference documents. (PDF p. 6)
    • The change log records intermediate drafts 6.7 Draft B (20/02/2010, SCR-3774/DCR-6008) and 6.7 Draft C (24/05/2010, R5.3.1, SPR 5504 on dynamic changes to TPSD). (PDF p. 5)
    • A new applicable document AD-6 (ADD-0022, SCOS-2000 System Control ADD) is added. (PDF p. 18)
    • RD-18 is now 'ICD NIS/NCTRS Volume 2 – MCS I/F', issue 4.0.2, November 2009 (version 6.7 Draft A cited 'NCTRA-NIS/MCS ICD Volume 2', issue 3.1, July 2005). (PDF p. 20)
    • PCF has 23 fields, ending with PCF_CORR, PCF_OBTID, PCF_DARC and PCF_ENDIAN; PCF_DESCR is Char(24). (PDF p. 40)
    • New section 3.3.2.1.5: the multi-domain System Control application (SCTL) starts, stops and monitors SCOS-2000 server families and stores status changes as TM packets; the tool SCTLgenerateMIB adds default PLF, PID, TPCF, OCF, OCP, TXF/TXP, DPF and DPC entries before SCTL first runs. (PDF p. 61)
    • CVS gains an optional seventh field CVS_UNCERTAINTY (Number(5), default -1) giving a stage-specific verification window that replaces the default (S2K-SCR-3774). (PDF p. 186)
    • CVE_CVSID and CVP_CVSID are aligned to Number(5), matching CVS_ID (S2K-DCR-3909). (PDF p. 250)
    • Unix-format absolute time (PTC=9, PFC=30, 8 octets) is listed in Appendix A as a type not defined in the PUS. (PDF p. 212)
    • Appendix C (PUS support) states that SCOS-2000 can encode and decode all PUS packet types and subtypes within the data-type limits, and details special processing for services 1, 2, 3, 4, 5, 6, 8, 9, 11, 12, 13, 14, 15, 17, 18 and 19. (PDF p. 227)
    • Annex 1 groups changes by release: all evolution releases, R4.0 (6.0), R4.1 (6.2/6.3), R5.0 (6.4/6.5), R4.2 (6.5), clarifications in 6.6, R5.2 (6.7) and 6.9. (PDF p. 234)

    Notes

    Third-party copy: downloaded from archive.org (item 'manualzilla-id-5725182'), not from an ESA site. The text contains residue of tracked changes, where deleted and inserted text run together: RD-1 is printed 'SUM-0002CG-0003' / 'SCOS-2000 Configuration and Installation GuideVariables' (7.0 has CG-0003 'SCOS-2000 Configuration Variables'); CVE_CVSID and CVP_CVSID types read 'Number(105'; and 'delfaultdefault' appears in CVS_UNCERTAINTY (p. 186). These are recorded as printed. The table-of-contents pages (PDF pp. 9-13) consist of dot-leader lines; printed page 1 is PDF page 15 (offset +14, with small drift in the appendices). Both PURPOSE and SCOPE are numbered 1.1. The digital-signature block on p. 2 includes an e-mail address, not reproduced here. Appendix C cites PUS sections via [AD-2]/[AD-5], as in 6.7 Draft A. Section 3.3.2.1.5 lists the SCTL-generated tables as 'PLF, PID, TPCF, OCF, OCP, TXT, TXP', where TXT presumably means TXF. Related library items: icd-6-7-drafta (predecessor draft), icd-7-0-final (successor), icd-5-1-tos-gci.
