    Library¶

    The library holds 200 sources used to write this wiki: standards, interface control documents, manuals, papers, presentations and MIB databases. Every entry has a summary, its table of contents, the documents it references, the wiki pages that cite it, a link to its original location, the UTC time it was copied, and a SHA-256 checksum of the copy kept in this repository. See Sources & copies for the provenance policy, and the reference catalogue for every document these sources cite.
