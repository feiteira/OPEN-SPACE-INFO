# dpc.dat: Alphanumeric displays definition

<div class="osi-chips"><span class="osi-chip">ICD 7.0 §3.3.2.7.2</span><span class="osi-chip">626 rows in Solar Orbiter 2025-09-16</span></div>

The dpc table defines the content of each Alphanumeric Display (AND) declared in dpf: one record per displayed monitoring parameter or per free-text comment, together with its position on the page. An AND has 64 positions (0 to 63); positions 0 to 31 are drawn in the left column and 32 to 63 in the right column. For each displayed parameter the record selects which sample of a super-commutated parameter is shown, whether the Telemetry Desktop setting for showing invalid values applies, and the number format (binary, octal, decimal, hexadecimal or the normal engineering/raw form). A record whose parameter name is empty is a free entry that displays a fixed text comment instead of a value. Only parameters processed by the telemetry model (plf-located TM parameters or synthetic parameters) can be displayed. As with dpf, from SCOS-2000 R5.0 these definitions are converted into XML display files in the FARC rather than imported into the run-time database.[^icd]

**Key:** `DPC_NUMBE`, `DPC_FLDN`

## Relationships

- `DPC_NUMBE` → [dpf.DPF_NUMBE](dpf.md#dpf_numbe): Many dpc records per AND.
- `DPC_NAME` → [pcf.PCF_NAME](pcf.md#pcf_name): Parameter must be processed by the TM model (plf entry or synthetic). Null for free-text entries.
- `DPC_COMM` → [plf.PLF_NBOCC](plf.md#plf_nbocc): Sample selection is meaningful for parameters with more than one occurrence in a packet (super-commutation).

## History across ICD issues

ICD 5.1 §3.3.2.6.2 (icd-5-1-tos-gci, PDF p.51-52) has only 6 fields: DPC_NAME is mandatory (no free entries), DPC_COMM has default '1' and range 1-9999 without the super-commutation explanation, and DPC_TEXT does not exist. ICD 6.0 (SCOS-2000 R4.0) introduced DCR-2422, display of super-commutated parameters in ANDs (ICD 7.0 Annex 1, PDF p.246), and the DPC change that allows free entries (PDF p.250); this gives the 7-field layout with optional DPC_NAME, DPC_TEXT and DPC_COMM default '0' already printed in ICD 6.7 Draft A (icd-6-7-drafta PDF p.104-106) and ICD 6.9 (icd-6-9-archive-org PDF p.108-110), and unchanged in ICD 7.0 (PDF p.111-113). ICD 6.0 also said that a multi-domain field for ANDs and SCDs, like GPC_DOMAIN, would only be supported from S2K R5.0 (PDF p.249), but no such field appears in dpc in ICD 7.0. Since SCOS-2000 R5.0 (ICD issue 6.4) display definitions are no longer kept in the run-time (POST) MIB database: the ASCII tables are converted on request into XML files stored in the FARC, in a delta fashion that keeps previously imported displays and displays created at run time with the TM Desktop editor (ICD 7.0 §2.5, PDF p.24; §3.3.2.7, PDF p.110; Annex 1, PDF p.254). The XML format is in [AD-5], SCOS-2000 TM Displays and Printout definitions Service ICD (ICD-5001), which is not in the library. Not modelled in pyscos2000 (7.2).

!!! note "Notes from the extraction"
    Column mapping: COL1..COL7 = DPC_NUMBE, DPC_NAME, DPC_FLDN, DPC_COMM, DPC_MODE, DPC_FORM, DPC_TEXT. All 626 lines of the 2025 dpc.dat have 7 fields, so the optional DPC_TEXT column is present (empty in 625 rows). Every DPC_NAME is filled and exists in pcf, so the file has no free-text entries; the only DPC_TEXT value ('Comment') is on the DQQA1234 test display, in a row that also names a parameter (NIA00510), so ICD 7.0 says the text is ignored. DPC_COMM is '1' in 625 rows and '0' in 1: the mission writes the ICD 5.1 default explicitly, whereas under ICD 7.0 a non-zero value selects one specific sample and '0' selects all samples. No displayed parameter has PLF_NBOCC &gt; 1 in plf, so the choice has no effect here. DPC_MODE is 'N' in 625 rows ('Y' once), so invalid values are forced visible. DPC_FORM is N 578, H 41, D 7. DPC_FLDN covers 0-63. Content is identical in the 2020-04-16 release. pyscos2000 has no dpc model. The HPSDB note (h-p-1-asp-tn-1060-mib-processing-hpsdb, PDF p.28) maps only 6 fields (no DPC_TEXT) and uses a DPC_COMM default of '1', as in ICD 5.1.
