# s13t.dat: Ground file types for on-board file uploads (inferred title)

<div class="osi-chips"><span class="osi-chip warn">not defined in the ICD</span><span class="osi-chip">12 rows in Solar Orbiter 2025-09-16</span></div>

!!! warning "Inference"
    This table is not defined by the SCOS-2000 Database Import ICD. Its column meanings below were inferred from the data and are this wiki's interpretation.

Inferred from the data; not documented in any available ICD. A lookup table (12 rows) of the kinds of ground files that can be turned into on-board files: unknown/plain files, OBCPs, SCOS stack files (SCOS0-SCOS3), TC sequences of four CSF types (mixed, plain, time-tagged, backup MTL), a binary plain file and a wildcard ALL. Each record holds the type name, a one-letter code (C or W), a numeric type code (-2 to 9), a format or converter name, a description, an optional file attribute (referring to s13a) and an optional default destination partition (referring to s13p), e.g. CSF2 'Time tagged TC sequence (CSF type 2)' goes by default to TCFA, OBCP to OBCA and CSF3 'Backup MTL' to SYSA. Together with s13a and s13p it appears to configure the ground tool that prepares files for upload through PUS service 13 (inference). SCOS-2000 itself does not use it.

**Key:** `COL1`
