# s13a.dat: File attribute codes for on-board file uploads (inferred title)

!!! warning "Inference"
    This table is not defined by the SCOS-2000 Database Import ICD. Its column meanings below were inferred from the data and are this wiki's interpretation.

Inferred from the data; not documented in any available ICD. A small lookup table (7 rows) of file categories used by Solar Orbiter's file-based uplink, which relies on PUS service 13 'large data transfer' commands such as TC(13,9) 'Accept First Uplink Part' whose application data include a Partition Id and a File Attribute. Each record gives a short name (PLAIN, OBCP, DEL, IMM, PAYLOAD, INVALID, OTHER), a one-letter code, a numeric code (0-6, repeated in two columns) and a description such as 'DELAYED TC' or 'IMMEDIATE TC'. The names OTHER and OBCP are referenced from column 6 of s13t, which suggests that s13a classifies the content of uploaded files (plain data, on-board control procedures, delayed or immediate telecommand sequences, payload context). The numeric codes do not match the on-board 'File types' textual calibration CCDT0082TX used by the File Attribute parameter (where 0 is FT_INVALID and 6 FT_PLAIN), so the codes are probably ground-side (inference). SCOS-2000 does not use this table; it belongs to mission tools.

**Key:** `COL1`
