# s13p.dat: On-board file partitions for uploads (inferred title)

<div class="osi-chips"><span class="osi-chip warn">not defined in the ICD</span><span class="osi-chip">11 rows in Solar Orbiter 2025-09-16</span></div>

!!! warning "Inference"
    This table is not defined by the SCOS-2000 Database Import ICD. Its column meanings below were inferred from the data and are this wiki's interpretation.

Inferred from the data; not documented in any available ICD. A lookup table (11 rows) of the on-board memory partitions that can receive uploaded files: the OMM mass-memory partitions for TC files, OBCPs, system files and spare (A and B sides, identifiers 161-164 and 177-180) and the SGM-EEPROM partitions for CSW TC files and default OBCPs (193-195). Each record holds a four-letter short name (e.g. TCFA, OBCA, SYSA), a one-letter class (M, B or N), the numeric partition identifier (twice), the short name again and a description such as 'OMM TC Files (A)'. The identifiers are exactly the values of the textual calibration CCDT0192TX ('Partition') used by command parameters such as PCD0D093 'Partition Id' of TC(13,9) 'Accept First Uplink Part', so this table is presumably used by the ground file-upload tooling to choose and label the destination partition. SCOS-2000 itself does not use it.

**Key:** `COL1`

## Relationships

- `COL3` → [pas.PAS_ALVAL](pas.md#pas_alval) (PAS_NUMBR = 'CCDT0192TX'): All 11 identifiers are values of the 'Partition' textual (de-)calibration used by command parameters PCD0D093, PCD85063, PCDP0002 and PCSB018D (inferred).
- `COL1` → s13t.COL7: Default partition of file types in s13t (inferred).

!!! note "Notes from the extraction"
    All meanings inferred. The descriptions differ slightly from the calibration texts: identifier 164 is 'OMM Spare (A)' here but OMM_PAYLOAD_A in CCDT0192TX (likewise 180). 'p' in the name possibly stands for 'partition' (inference).
