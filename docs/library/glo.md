## Summary

The **EDDS Glossary** is the common terminology and bibliography volume of the documentation set of the [EGOS Data Dissemination System (EDDS)](../scos2000/edds.md), ESOC's system for disseminating archived and live mission data from [SCOS-2000](../scos2000/index.md) to external users. Every other EDDS document (CIG, SDD, SRS, SUM, EUICD, update guide) refers to it as [GLO] instead of carrying its own lists.

It has three parts. Section 2 lists the applicable documents of the EDDS project: the ESA BSSC tailoring of the ECSS software standards for ground segments (SETG), the EDDS statement of work and project plans, the ESOC Generic Ground Systems (EGGS) configuration baselines, the EGOS document template guidelines, the ESA network security policy, BSSC Java and XML coding standards, and the early EDDS EUICD and [GDDS](../scos2000/gdds-and-ddids.md) RDM interface documents. Section 3 lists 41 reference documents, which give a useful view of EDDS's lineage: analyses of reusing [TDRS](../scos2000/tdrs.md), WebRM, GDDS and MUST, the SCOS-2000 TM Data Retrieval Services SRD, the TDRS ICD, the Generic Data Delivery Interface Document (GDDID), SCOS-2000 SMF service ICDs, the DARC ICD and SDD, CCSDS SLE and XFDU (CCSDS 661.0-B-1) standards. Sections 4 and 5 define about 140 acronyms (for example PARC, DARC, FARC, RDM, SPID, SCET, OBQ, OBSM) and three terms (smoke test, software predeliveries, virtual appliance).

Engineers use it to decode EDDS acronyms and to trace where EDDS sits among the ESOC ground-segment documents and standards.


## Key points

- The glossary is the single place where EDDS documents define applicable/reference documents, acronyms and terms; it is referenced by all other EDDS documents. *(PDF p. 4)*
- The document follows the SETG standard (ESA BSSC tailoring of ECSS software engineering standards for ground segments) and sits in the SWRR document package beside the SoW, SRS, SDP, SPAP, SCMP and SVVP. *(PDF p. 4)*
- Change log: first issued 2010-01-18 for the Software Requirements Review; issue 7.0 of 2017-04-10 is 'Updated for EDDS v1.8.0i1'. *(PDF p. 2)*
- Among EDDS's predecessors and inputs the reference list cites the SCOS-2000 TM Data Retrieval Services SRD (S2K-MCS-SRD-0004-TOS-GIC), the TDRS External Interfaces Control Document (S2K-MCS-ICD-0017-TOS-GIC) and the Generic Data Delivery Interface Document (EGOS-MCS-GDDS-ICD-1003). *(PDF p. 7)*
- CCSDS standards cited: the SLE Cross Support Reference Model (910.4-B-1) and XML Formatted Data Unit (XFDU) Structure and Construction Rules (CCSDS 661.0-B-1, Blue book, 09.2008). *(PDF p. 8)*
- Acronyms defined include DARC (Data Archive), FARC (File Archive), GDDS (Generic Data Disposition System) and DDID (Data Delivery Interface Document). *(PDF p. 9)*
- PARC is expanded as Packet ARChive and MUST as Mission Utility & Support Tool; OBQ, OBSM and OOL are also defined. *(PDF p. 10)*
- SPID is expanded as 'SCOS- 2000 Packet ID', SCET as Spacecraft Event Time, SSC as Source Sequence Count, RDM as Raw Data Media and TDRS as Telemetry Data Retrieval Service. *(PDF p. 11)*
- Only three terms are defined: smoke test, software predeliveries (mock-ups and intermediate deliveries) and virtual appliance. *(PDF p. 13)*
