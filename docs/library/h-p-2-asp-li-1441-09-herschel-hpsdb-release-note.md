## Summary

The release note that accompanied one delivery of the Herschel/Planck System Data Base (HPSDB), Thales Alenia Space's industrial system database, to Astrium (ASED, Friedrichshafen). The delivery is a set of MIB files in Central Checkout System (CCS) format, filtered for AIT users, for the Herschel flight model theoretical model HERSCH_FM9. It was generated by HPSDB version 3.3.1.30 on 07/04/2008 for the Herschel IRR, and it added CDMS on-board software 3.4 and OBCP version 11.

The note follows a fixed configuration-item template: configuration item 460000, supplier, the inputs per level (generic, element, subsystem, model) with their source deliveries (HIFI 11.6, SPIRE 2.2.H1 PR, PACS 8.17, cryostat, service module, system), input changes and open NCRs, and the DBAMN database amendment requests applied. It also tabulates TM packet routing (which subsystem TM goes to which instrument EGSE, from the TMD file) and TC packet routing by APID (from the TCD file).

The output section shows the model's object tree, the theoretical subsystems at numbered positions (ACMS A105, CDMS D108, HIFI H004, cryostat K002, PACS P002, RF R101, SPIRE S002, thermal T101, power W101, EGSE Y104) with their elements. It also gives the MD5 checksum and the file-naming convention of HPSDB exports, which encodes the area, the object box type and the MIB flavour (CCS, S2K or MCS). An NCR annex records issues such as the SPIRE event naming fix and an APID curve listing the instrument APIDs. For an engineer it shows how instrument MIBs were integrated and configuration-controlled into one spacecraft database.


## Key points

- Delivery from Central Site HPSDB v3.3.1.30 to ASED (Friedrichshafen) of theoretical model HERSCH_FM9, file type CCS, AIT user filter, file R_TM_HERSCH_FM9_C_804071709.zip, for the Herschel IRR. *(PDF p. 8)*
- Inputs are assembled by level: generic data (generic), bus profile and OBCP (element), HIFI, SPIRE, PACS and cryostat (subsystem), SVM and system data (model). *(PDF p. 8)*
- Open NCRs on the instrument EGSE inputs include file formats not compatible with Windows, extra spaces in cpc.dat and a missing tpcf.dat. *(PDF p. 9)*
- The TCD (TC packet routing) configuration maps APIDs to equipment: for example APIDs 0, 16, 512, 1024, 1152, 1280 and 2020 to TMTCDFE, 2017 to CDMUSCOE, 2026 to PFM_CRYO and 2042/2043/2044 to the HIFI, PACS and SPIRE EGSEs. *(PDF p. 10)*
- Model HERSCH_FM9 groups theoretical subsystems at positions: A105 ACMS 3.7, D108 CDMS 3.4, H004 HIFI FM v11_6, K002 Cryostat, P002 PACS FM 8.17, R101 TTC_HER, S002 SPIRE FM 2.2.H1 PR, T101 TCS_HER, W101 EPS_H and Y104 EGSE. *(PDF p. 11)*
- The delivery checksum type is MD5, and the release is identified as H-P-2-ASP-LI-1441 v 09.0 generated on 07/04/2008. *(PDF p. 17)*
- HPSDB export file naming: &lt;Area&gt;_&lt;Box&gt;_&lt;Object name&gt;_&lt;MIB type&gt;_&lt;Date&gt;_&lt;M&gt;.zip, with Area R/A/W (reference, archive, working), Box TE/TS/TM/RM etc., MIB type C (CCS), S (S2K) or M (MCS), the date as YMMDDHHMN and an optional M flag for manual updates. *(PDF p. 17)*
- Applicability: Herschel model with CDMS 3.4, ACMS 3.7, PACS 8.17, HIFI 11.6 and SPIRE 2.2.H1 PR software. *(PDF p. 18)*
- SPIRE MIB 2.2 H1 PR: all TM(5,2) and TM(5,4) events now carry the SPIRE_ prefix in PID_DESCR, and their PID_EVENT field is set to W and A respectively. *(PDF p. 20)*
- Curve 170016 maps APID values to names: 16 CDMS, 512 ACMS, 1024 HIFI_N, 1025 HIFI_R, 1152 PACS_N, 1153 PACS_R, 1280 SPIRE_N, 1281 SPIRE_R. *(PDF p. 21)*
