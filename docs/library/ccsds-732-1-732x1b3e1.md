## Summary

The CCSDS Recommended Standard for the **Unified Space Data Link Protocol (USLP)**. USLP is a single Data Link Layer protocol for space-to-ground, ground-to-space and space-to-space links. It defines the Version-4 Transfer Frame (TFVN '1100'), and its frames can be fixed or variable length, up to 65,536 octets. It can run over TM, TC or Proximity-1 synchronisation and coding, FACM or DVB-S2. USLP unifies what the [TM](../ccsds/tm-sdlp.md), [TC](../ccsds/tc-sdlp.md), [AOS](../ccsds/aos.md) and Proximity-1 protocols do separately. The wiki page is [USLP](../ccsds/uslp.md).

Section 2 gives an overview of the protocol: Physical Channel, Master Channel (identified by the 20-bit MCID), Virtual Channel and MAP channel, the services and the functions. Section 3 defines ten services: MAP Packet, VC Packet, MAP Access, VC Access, MAP Octet Stream, USLP MC_OCF, VC Frame, MC Frame, Insert and COPs Management. Section 4 specifies the frame. The Primary Header has 13 fields, 4 to 14 octets in all: TFVN, a 16-bit SCID, the Source-or-Destination ID, a 6-bit VCID, a 4-bit MAP ID, the End of Frame Primary Header Flag, a 16-bit Frame Length, the Bypass/Sequence Control and Protocol Control Command flags, the OCF Flag, and a VCF Count of variable length (0-56 bits). It is followed by an optional Insert Zone, the Transfer Frame Data Field (a 1-3 octet header with the TFDZ Construction Rule, the UPID and the First Header/Last Valid Octet Pointer), an optional OCF and an optional CRC-16 FECF. Section 4 also gives the sending and receiving procedures, including COP-1 and COP-P interaction. Section 5 lists the managed parameters per channel and section 6 adds [SDLS](../ccsds/sdls.md). The annexes contain the PICS, the FECF CRC, the Proximity-1 relationship, the 4-octet truncated frame for short telecommands, the SANA registries (UPID, SCID range C0000-CFFFF) and OID randomization.


## Key points

- Issue 3 (June 2024) adds the VC Packet and VC Access services, raises the maximum number of frames per CLTU from one to more than one (matching TC), and adds a table, diagram and text on the order of COP and SDLS. EC 1 (October 2024) is editorial only. *(PDF p. 7)*
- Out of scope: the COP-1 and COP-P procedures themselves, the SDLS security services, flow control, implementations, and management activities. *(PDF p. 13)*
- A USLP Transfer Frame consists of a Primary Header (4-14 octets), an optional Insert Zone, the Transfer Frame Data Field (TFDF header of 1-3 octets plus the TFDZ), an optional 4-octet OCF and an optional 2-octet FECF. *(PDF p. 89)*
- The non-truncated Primary Header has 13 fields: TFVN (4 bits), SCID (16), Source-or-Destination ID (1), VCID (6), MAP ID (4), End of Frame Primary Header Flag (1), Frame Length (16), Bypass/Sequence Control Flag (1), Protocol Control Command Flag (1), Reserve Spares (2), OCF Flag (1), VCF Count Length (3) and VCF Count (0-56 bits). *(PDF p. 90)*
- The TFVN is '1100' binary, the USLP Version-4 Transfer Frame. The MCID is bits 0-19 (TFVN plus SCID). *(PDF p. 91)*
- The Frame Length field holds the total octets minus one, so a frame is limited to 65536 octets. Frames can be fixed or variable length; if the Physical Channel is fixed length, the subordinate MCs and VCs are fixed length too. *(PDF p. 93)*
- End of Frame Primary Header Flag = 1 marks a truncated Primary Header containing only the first six fields. It is intended for short forward-link or direct-from-Earth telecommands. *(PDF p. 93)*
- Bypass/Sequence Control Flag: 0 means a Sequence-Controlled frame, subject to the FARM acceptance checks; 1 means an Expedited frame, which bypasses them. It is equivalent to the Proximity-1 QoS Indicator. *(PDF p. 94)*
- VCID 63 is the only VC used for Only Idle Data (OID) frames. OID frames carry a randomized idle pattern from an LFSR initialised only at device start-up. *(PDF p. 99)*
- The TFDF Header has a 3-bit TFDZ Construction Rule, a 5-bit USLP Protocol Identifier (UPID, registered with SANA) and an optional 16-bit First Header/Last Valid Octet Pointer. There are eight construction rules; for example, '000' means fixed-length TFDZ packets spanning frames, with an FHP. *(PDF p. 100)*
- The FECF, if present, occupies the last 16 bits of every frame and is computed with the CRC-16 procedure of Annex B. *(PDF p. 107)*
- A truncated frame has a 4-octet header plus the TFDF only, with no Insert Zone, OCF or FECF. It is allowed only on variable-length VCs. SDLS on truncated frames needs a Truncated Transfer Frame Length of at least 28 octets. *(PDF p. 186)*
- SANA: the new UPID registry; for Version 4 the SCID range is 0x0000-0xFFFF and the GSCID (= MCID) range is C0000-CFFFF; MAP IDs are '0000'-'1111'. *(PDF p. 191)*
