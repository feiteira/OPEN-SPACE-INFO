## Summary

The CCSDS Recommended Standard for the **Return Operational Control Fields (ROCF)** service of the [Space Link Extension](../ccsds/sle/index.md). ROCF delivers to a mission user the 4-octet Operational Control Fields (OCFs) extracted from the good-quality frames of **one Master Channel or one Virtual Channel** of a TM, AOS or USLP return link. The document notes that the most common OCF payload is the **CLCW** of the Communications Operation Procedure (see [COP-1](../ccsds/cop-1.md)). It can also deliver other control-word types such as the SDLS Frame Security Report. ROCF replaces the separate Rtn MC-OCF and Rtn VC-OCF services of the SLE Reference Model. It is described with RAF and RCF on [SLE return services](../ccsds/sle/return-services.md).

Section 2 explains production: the RFP-FG takes a RAF data channel, keeps only 'good' frames, and demultiplexes by MC and VC. It also covers service management, the delivery modes (timely online, complete online, offline), buffering and security. Section 3 defines the operations. ROCF-BIND carries version number '6'. ROCF-START takes start/stop time, requested-global-VCID, control-word-type ('all control word types', 'clcw' or 'not clcw'), tc-vcid (only for 'clcw': pick the CLCWs that report on one TC Virtual Channel, or 'null' for all of them) and update-mode ('continuous', or 'change-based', which delivers an OCF only when its content changes). The other operations are UNBIND, STOP, TRANSFER-DATA (ERT, antenna-ID, data-link-continuity, private-annotation, OCF data), SYNC-NOTIFY, SCHEDULE-STATUS-REPORT, STATUS-REPORT, GET-PARAMETER and PEER-ABORT. Section 4 gives the provider state machine. The annexes hold the ASN.1 modules, the production status model, the conformance matrix, an index and acronyms.


## Key points

- Issue 4 (July 2023) adds support for USLP Transfer Frames plus clarifications and corrections. EC 1 (October 2024) repairs figure 2-3. *(PDF p. 6)*
- ROCF delivers to a mission user all operational control fields from one Master Channel or one Virtual Channel. It merges the Rtn MC-OCF and Rtn VC-OCF services of the SLE Reference Model into one. *(PDF p. 9)*
- The ROCF delivery criteria are: ERT within the start/stop window, SCID and VCID matching the requested global VCID, a matching control word type, and, for CLCWs (control word type '0'), a matching telecommand VC. For 'not clcw' OCFs, the Frame Security Report can be delivered. *(PDF p. 17)*
- The most common OCF payload is the CLCW of the COP, which has no confidentiality protection, so the confidentiality of ROCF data usually depends entirely on the underlying communications service. *(PDF p. 46)*
- Only frames annotated 'good' feed ROCF production: valid Reed-Solomon or LDPC codewords, or a correct FECF for uncoded frames. *(PDF p. 30)*
- The version-number value for the ROCF service defined by this issue is '6'. *(PDF p. 66)*
- The ROCF-START invocation carries invoker-credentials, start-time, stop-time, requested-global-VCID, control-word-type, a conditional tc-vcid and update-mode. The return carries performer-credentials, result and diagnostic. *(PDF p. 74)*
- control-word-type is 'all control word types', 'clcw' (type '0') or 'not clcw'; 'not clcw' is the type to use to obtain FSRs. tc-vcid is present only for 'clcw', and 'null' selects CLCWs for every TC VC. *(PDF p. 77)*
- In update-mode 'continuous' every matching OCF is delivered. In 'change-based' an OCF is delivered only if its content differs from the last one delivered for the same tc-vcid, or if none has been delivered since the most recent START. *(PDF p. 78)*
- ROCF-TRANSFER-DATA carries invoker-credentials, earth-receive-time, antenna-ID, data-link-continuity, private-annotation and the OCF data. *(PDF p. 83)*
- GET-PARAMETER exposes delivery-mode, latency-limit, minimum-reporting-cycle, permitted-global-VCID-set, permitted-control-word-type-set, permitted-tc-vcid-set, permitted-update-mode-set, reporting-cycle, requested-control-word-type, requested-global-VCID, requested-tc-vcid, requested-update-mode, return-timeout-period and transfer-buffer-size. *(PDF p. 100)*
- Annex A defines the common SLE ASN.1 modules plus CCSDS-SLE-TRANSFER-SERVICE-ROCF-STRUCTURES, -ROCF-INCOMING-PDUS and -ROCF-OUTGOING-PDUS. *(PDF p. 119)*
