## Summary

The CCSDS Recommended Standard that adopts the **Object Management Group's XML Telemetric and Command Exchange (XTCE) specification, version 1.2** (OMG formal/18-10-04, January 2019) as the CCSDS exchange format for telemetry and telecommand definitions. The CCSDS wrapper adds only front matter (authority, statement of intent, document control) to the OMG text. The normative content is the XML schema `SpaceSystem.xsd`, which OMG publishes as a machine-readable file and which is not printed here. See [XTCE](../ccsds/xtce.md).

XTCE is a *metadata* format. It describes how telemetry and commands are structured, encoded, calibrated, constrained and verified, so that a spacecraft manufacturer, a test facility, a simulator and a control centre can exchange a TM/TC database without writing custom import/export tools. The specification avoids both packet and TDM nomenclature. It does not cover live data transfer, displays, protocols or flight software. The root object is the hierarchical **SpaceSystem**. It contains an optional Header, nested sub-SpaceSystems, **TelemetryMetaData** (ParameterTypeSet, ParameterSet, ContainerSet, MessageSet, StreamSet, AlgorithmSet) and **CommandMetaData** (which adds ArgumentTypeSet and MetaCommandSet). The document explains the four data encodings (integer, float, string, binary) and container inheritance, where a BaseContainer with RestrictionCriteria identifies a packet subtype. For commands it describes transmission constraints, significance levels, alarm suspension, interlocks and the eight verifier stages. The bibliography cites the SCOS-2000 Database Import ICD and the ESA PUS, so XTCE is the natural counterpart of the [SCOS-2000 MIB](../mib/index.md).


## Key points

- 660.0-B-2 (February 2020) is the current issue; 660.0-B-1 (October 2007) is superseded. *(PDF p. 7)*
- The CCSDS book embeds the OMG publication XML Telemetric and Command Exchange Version 1.2, OMG Document Number formal/18-10-04, released January 2019. Its normative machine-consumable file is https://www.omg.org/spec/XTCE/20180204/SpaceSystem.xsd. *(PDF p. 9)*
- Copyright holders of the specification text: Boeing Satellite Systems, the European Space Operations Centre, Lockheed Martin – Integrated Systems & Solutions (all 2018), and the Object Management Group (2014-2018). *(PDF p. 10)*
- XTCE deliberately avoids both packet and TDM terminology ('minor frame', 'major frame', 'packet' appear only in examples) and does not itself use CCSDS or IRIG-106 formats, though such containers can be modelled with it. *(PDF p. 16)*
- Out of scope: data distribution, command and data protocols, RF characterisation, data grouping, visualisation, scheduling, orbital properties, displays and flight software. XTCE is a metadata specification, not a specification for transferring live or historical TM/TC data. *(PDF p. 19)*
- Conformance: the schema (.xsd) in Annex A is normative, and a compliant database is an XML file that validates against it. *(PDF p. 19)*
- Names may contain only digits, a-z letters, underscores, hyphens or backslashes and are case sensitive. '/', '.', '[', ']' and ':' are reserved; '/' separates SpaceSystems in a hierarchical path. *(PDF p. 23)*
- There are four parameter encodings. IntegerDataEncoding: unsigned, signMagnitude, twosCompliment, onesCompliment, BCD, packedBCD. FloatDataEncoding: IEEE754_1985 or MILSTD_1750A. StringEncoding: UTF-8 or UTF-16, fixed or terminated/size-prefixed. BinaryDataEncoding. *(PDF p. 25)*
- SequenceContainers may inherit from a BaseContainer, and RestrictionCriteria (a MatchCriteria) distinguish a subtype. This is how XTCE identifies packets, for example 'minor frame counter equals 20'. *(PDF p. 27)*
- MetaCommands carry an ArgumentList, CommandContainer, TransmissionConstraintList, significance (none, watch, warning, distress, critical, severe), ParametersToSuspendAlarmsOn, Interlock, Verifiers and ParameterToSetList. *(PDF p. 32)*
- There are eight command verifier stages: TransferredToRange, TransferredFromRange, Received, Accepted, Queued, Execution, Complete and Failed. A command may have several 'Complete' verifiers. *(PDF p. 33)*
- The bibliography lists the SCOS-2000 Database Import ICD Issue 5.0 (S2K-MCS-ICD-0001-TOS-GCI) and the SCOS-2000 Synthetic Parameters SUM as inputs to XTCE. *(PDF p. 39)*
