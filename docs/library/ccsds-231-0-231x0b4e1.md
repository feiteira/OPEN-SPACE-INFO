## Summary

The CCSDS Recommended Standard for the **TC Synchronization and Channel Coding Sublayer**, the uplink counterpart of [TM coding](../ccsds/tm-coding.md). It takes variable-length [TC](../ccsds/tc-sdlp.md) or [USLP](../ccsds/uslp.md) Transfer Frames, protects them with error-control coding, wraps them in a **Communications Link Transmission Unit (CLTU)** and hands them to the Physical Layer through a Physical Layer Operations Procedure (PLOP). It is the specification behind every telecommand decoder on board and behind the CLTUs a ground station radiates, including those delivered through [SLE FCLTU](../ccsds/sle/fcltu.md). The rationale and worked examples are in [230.1-G-3](ccsds-230-1-230x1g3e1.md).

Section 2 lists four functions: error-control coding, synchronization, optional pseudo-randomizing and optional repeated transmissions. Section 3 defines the modified (63,56) BCH code with generator g(x) = x^7+x^6+x^2+1, which gives 64-bit codewords of 56 information bits, 7 inverted parity bits and a zero filler bit, padded with alternating-bit fill. It can be decoded in error-detecting or error-correcting mode. Section 4 defines the rate-1/2 (128,64) and (512,256) LDPC codes through their parity-check and circulant generator matrices. Section 5 defines the CLTU: Start Sequence (16-bit 0xEB90 for BCH, 64-bit 0x034776C7272895B0 for LDPC), codewords and Tail Sequence (C5C5 C5C5 C5C5 C579 for BCH, an optional 128-bit pattern for LDPC (128,64), none for (512,256)). It also gives the receiver state machine with states S1 Inactive, S2 Search and S3 Decode and events E1 to E5. Section 6 specifies the Bit Transition Generator randomizer, h(x) = x^8+x^6+x^4+x^3+x^2+x+1, which is optional with BCH and mandatory with LDPC. Section 7 specifies the carrier modulation modes CMM-1 to CMM-4 and PLOP-1 and PLOP-2, and section 8 the managed parameters. Annex A gives the ChannelAccess service with its optional Repetitions parameter.


## Key points

- Issue 4 (July 2021) clarifies the short-LDPC procedures and adds USLP support; EC 1 (October 2024) fixes the table of contents and moves to A4. *(PDF p. 7)*
- Four sublayer functions: error-control coding, synchronization, pseudo-randomizing (optional) and repeated transmissions (optional). *(PDF p. 18)*
- The modified BCH code can be decoded in error-detecting or error-correcting mode; the FECF of the TC or USLP frame can lower the undetected-error probability, especially in error-correcting mode. *(PDF p. 19)*
- Repeated transmission is requested with an optional Repetitions parameter in the service primitive; how the repetitions are performed is not specified. *(PDF p. 20)*
- BCH codeword: 56 information bits plus 7 parity bits from g(x) = x^7 + x^6 + x^2 + 1 plus a filler bit that is always zero, 64 bits (8 octets) in total. *(PDF p. 24)*
- Two rate-1/2 LDPC codes are specified, (n=128, k=64) and (n=512, k=256), built from M x M circulant submatrices with M = k/4. *(PDF p. 27)*
- CLTU = Start Sequence + encoded codewords + Tail Sequence. For BCH, the Start Sequence is 16 bits (0xEB90) and the Tail Sequence is 64 bits (C5C5 C5C5 C5C5 C579). *(PDF p. 30)*
- For LDPC, the Start Sequence is 64 bits (0347 76C7 2728 95B0); an optional 128-bit Tail Sequence (5555 5556 AAAA AAAA 5555 5555 5555 5555) applies only to LDPC (128,64), and no tail is used with (512,256). *(PDF p. 31)*
- CLTU reception states are S1 INACTIVE, S2 SEARCH and S3 DECODE; events E1 to E5 are channel activation, channel deactivation, start sequence found, codeword rejection and (for LDPC 128,64) tail sequence detected. *(PDF p. 33)*
- The randomizer polynomial is h(x) = x^8 + x^6 + x^4 + x^3 + x^2 + x + 1, starting from all ones; randomization is always applied with LDPC and required with BCH unless proper operation without it is verified. *(PDF p. 36)*
- With BCH the BTG is preset at the start of the Transfer Frame(s); with LDPC it is preset at the start of each codeword and reset after each codeword. *(PDF p. 37)*
- PLOP-2 shall be used for missions whose planning begins after September 2010; the preferred minimum Acquisition Sequence length is 16 octets. *(PDF p. 39)*
- Carrier Modulation Modes: CMM-1 unmodulated carrier, CMM-2 carrier with acquisition sequence, CMM-3 carrier with CLTU, CMM-4 carrier with idle sequence. *(PDF p. 40)*
- Managed parameters: code type (BCH or LDPC), maximum CLTU length, maximum Repetitions, PLOP-1 or PLOP-2; for BCH also the decoding mode, allowed errors in the Start Sequence (0 or 1) and randomizer use; for LDPC the code length and use of the tail sequence. *(PDF p. 44)*
