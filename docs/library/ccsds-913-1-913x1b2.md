## Summary

The CCSDS Recommended Standard for the **Internet SLE Protocol One (ISP1)**, the wire protocol that carries the SLE transfer-service PDUs of [RAF, RCF, ROCF](../ccsds/sle/return-services.md), [FCLTU](../ccsds/sle/fcltu.md) and FSP over TCP/IP. The service specifications define the operations but deliberately leave out communications, and this document fills that gap. It is the subject of [SLE over TCP/IP (ISP1) and the SLE API](../ccsds/sle/isp1-and-api.md).

Section 2 gives a layered model. The Authentication Layer (AL) generates and checks credentials. The Data Encoding Layer (DEL) encodes the service's ASN.1 types with BER. The Transport Mapping Layer (TML) maps one SLE association onto exactly one TCP connection. Section 2 also defines the primitives of each interface (AL, DEL, TML data transfer, association control and listener) and the use of TCP, and covers security. Section 3 specifies the messages and procedures. Authentication follows the ISO/IEC 9594-8 'Protected 1' simple scheme: a DER-encoded HashInput (CCSDS CDS time, random number, user name of 3-16 characters, password of 6-16 octets) is hashed with **SHA-256**, and the time, random number and digest travel in the ISP1Credentials. The authentication level per service instance is 'all', 'bind' or 'none'. TML messages have an 8-octet header (type 1 SLE PDU, 2 Context, 3 Heartbeat; 3 reserved octets; a 4-octet length) and are big-endian. The 12-octet context message carries 'ISP1', version 1, the heartbeat-interval and the dead-factor. The section also covers heartbeat timers, connection establishment and release, and PEER-ABORT sent as one octet of TCP urgent data. Section 4 is the TML state table (S0 Closed to S4 TML Closing), Annex A lists the TML diagnostic codes, and Annex B covers interoperability with the earlier ESA 'SLE API Proxy' specification, from which ISP1 derives.


## Key points

- Issue 2 (September 2015) changes the recommended one-way hash function from SHA-1 to SHA-256 and updates references. Issue 1 (September 2008) is superseded. *(PDF p. 7)*
- ISP1 transfers the SLE PDUs defined in the SLE transfer service standards over TCP and IP, using ASN.1 for data encoding. *(PDF p. 10)*
- The architecture has three layers above TCP/IP: the Authentication Layer (AL), the Data Encoding Layer (DEL) and the Transport Mapping Layer (TML), plus a TML association-control interface and a listener interface. *(PDF p. 19)*
- The user name is 3-16 characters and equals the authority identifier used in BIND. The password is 6-16 octets. The authentication level is 'all' (every PDU except PEER-ABORT), 'bind' (only BIND invocation and return) or 'none'. *(PDF p. 44)*
- Credentials follow the 'Protected 1' simple authentication procedure of ISO/IEC 9594-8. A DER-encoded HashInput holds the time as an 8-octet CCSDS CDS code without P-field, a random number (0..2147483647), the user name and the password. *(PDF p. 44)*
- The hash function is SHA-256 (FIPS 180-4). ISP1Credentials carries the time, the random number and 'theProtected' (20..32 octets; 20 octets keeps compatibility with SHA-1 implementations). *(PDF p. 46)*
- The DEL encodes SLE PDUs with the ASN.1 types of the applicable service specification and version, using BER. The first PDU on an association must be the BIND invocation. *(PDF p. 46)*
- The TML maps one SLE association to exactly one TCP connection and uses three message types: 1 SLE PDU, 2 TML Context and 3 TML Heartbeat. Each message has an 8-octet header: a 1-octet type, 3 reserved octets and a 4-octet body length. *(PDF p. 47)*
- The TML context message body is 12 octets: 'ISP1' (hex 49 53 50 31), 3 reserved octets, protocol version 1, a 2-octet heartbeat-interval and a 2-octet dead-factor. The heartbeat message body is empty. All integers are big-endian. *(PDF p. 48)*
- Heartbeat: the HBT timer (heartbeat-interval) triggers a heartbeat message when the link is idle. When the HBR timer (heartbeat-interval × dead-factor) expires, the TML issues TCP-ABORT with the diagnostic 'heartbeat timeout'. An interval of 0 disables the mechanism. *(PDF p. 49)*
- PEER-ABORT sends its diagnostic as one byte of TCP urgent data. The receiver discards buffered data up to the urgent pointer and then reads the diagnostic. *(PDF p. 27)*
- The TML states are S0 CLOSED, S1 TML STARTING, S2 DATA TRANSFER, S3 PEER ABORTING and S4 TML CLOSING. *(PDF p. 58)*
- ISP1's precursor is ESA's 'Specification of a SLE API Proxy for TCP/IP and ASN.1' (SLES-SW-API-0002-TOS-GCI). Its authentication scheme and service instance identifier come from ESA's SLE C++ API (SLES-SW-API-0001-TOS-GCI). *(PDF p. 67)*
