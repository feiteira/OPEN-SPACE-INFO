## Summary

The Solar Wind Analyser (SWA) instrument database in SCOS-2000 MIB table format, posted by the SWA/PAS team at IRAP next to the spacecraft MIB releases. The zip was copied unchanged; the wiki's [MIB Explorer](../explorer/index.md#/swa) is generated from it.
