## Summary

The Spectrometer/Telescope for Imaging X-rays (STIX) instrument database in SCOS-2000 MIB table format, published by the STIX team at FHNW in an open directory that the team's STIXCore software downloads from. The zip was copied unchanged; the wiki's [MIB Explorer](../explorer/index.md#/stix) is generated from it.
